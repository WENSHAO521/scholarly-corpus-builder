Scholarly Corpus Builder

A provenance-aware pipeline that acquires, resolves, samples, and analyzes scholarly literature into compact writing profiles — for discipline, journal, historical_scholar, author, and book corpora — without warehousing full text it doesn't need.

45scb/ modules
284unit tests
150eval fixtures
6live adapters
9OA states

Principle

Minimize lawful retrieval while maximizing evidentiary sufficiency — never the other way around.

Every stage below exists to answer one narrow question with the least material necessary, then stop. A journal profile needs 20–50 diversified articles, not every issue the venue ever published; a discipline profile needs abstracts, not full text, until a specific feature demands otherwise. The pipeline tracks four retrieval depths — LEVEL_0_METADATA through LEVEL_3_FULLTEXT — and a caller who only asks for metadata gets exactly that, counted as fully usable, not penalized for stopping early.

Nothing here bypasses a paywall, probes a hidden URL, or fabricates a source count. When an upstream API changes shape underneath it — as OpenAlex and PMC both did during this build — the adapter is fixed and the finding is written down, not quietly patched over.

Pipeline

One corpus request, traced end to end from intake to the protocol a downstream writing skill actually consumes.

What each stage actually guarantees

Not aspirations — behavior enforced by the test suite.

Deduplicator Never merges two records on title similarity alone; a fuzzy match without a shared identifier or matching author/year is routed to REVIEW_REQUIRED, not silently combined.
Version Resolver bibliographic_authority and best_lawful_access are tracked independently — a closed version of record never overwrites an open accepted manuscript, or vice versa.
OA Resolver Never probes a hidden publisher URL and never fabricates a link that wasn't actually present on the record — if nothing lawful was found, it says so.
Corpus Manifest usable means "met the retrieval depth actually requested" — a metadata-only request that gets metadata is complete, not penalized against an abstract-level bar.
Style Analytics Claim, rhetorical-move, and rhythm classifiers are rule-based cue matching, English-only, and every output is labeled inferred — never presented as measured fact.
Stability Engine Actually runs a deterministic split-corpus comparison before calling anything stable; below ten documents it reports INSUFFICIENT_SAMPLE rather than guessing.
Profile Compiler MANDATORY is only ever set from an author's own corrections or caller-supplied official requirements — never invented from an observed pattern.
Multilingual English-cue analytics are marked not_applicable for other languages rather than reported as a misleading near-zero measurement.
Scope Two adapters needed real fixes mid-build — OpenAlex deprecated a select field, NCBI retired PMC's per-article OA lookup outright — and the manifest's own usable-count logic had a depth-blindness bug, all found by testing against live traffic rather than assumed correct. No cross-disciplinary, human-reviewed benchmark and no Voice Engine to A/B against exist yet; that ceiling is stated in the repository, not smoothed over here.
